📚 For teachers & parents

Every game shares the same lesson word sets — Home Row → Top Row → Bottom Row → Numbers → Full Keyboard — so skills carry across the whole arcade. Each tracks live WPM and accuracy.

🔒 Safe & simple

No accounts, no ads, no data collected. Everything runs right in the browser, fully offline once loaded. Best experienced in Google Chrome on a real keyboard.

🚀 Setup

Keep this page and all six velocity-*.html game files in the same folder. Open this index.html to start. Host the folder anywhere to share one link.
